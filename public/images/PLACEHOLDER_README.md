# Placeholder Images

This directory contains placeholder images for the marketplace landing page.

## Required Images

Replace these placeholder paths with actual images:

### Hero Section
- `/images/hero/background.jpg` - Hero background image (1920x1080)
- `/images/hero/thumbnail.jpg` - Video thumbnail (1280x720)
- `/videos/hero-showcase.mp4` - Hero video (optional)

### Categories
- `/images/categories/furniture.jpg` - Furniture category (800x600)
- `/images/categories/electronics.jpg` - Electronics category (800x600)
- `/images/categories/fashion.jpg` - Fashion category (800x600)

### Testimonials
- `/images/testimonials/sarah.jpg` - Sarah's avatar (200x200)
- `/images/testimonials/michael.jpg` - Michael's avatar (200x200)

### CTA Section
- `/images/cta/background.jpg` - CTA background image (1920x600)

### Logo
- `/images/logo.svg` - Company logo (already created as SVG)

## Image Specifications

- **Hero images**: 1920x1080px, optimized for web
- **Category images**: 800x600px (4:3 aspect ratio)
- **Testimonial avatars**: 200x200px (1:1 aspect ratio)
- **CTA background**: 1920x600px
- **Format**: JPG for photos, PNG for graphics with transparency, SVG for logos
- **Optimization**: Compress images to reduce file size while maintaining quality
