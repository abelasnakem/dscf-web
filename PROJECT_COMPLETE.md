## 🚀 How to Use

### 1. Start Development Server
```bash
npm install
npm run dev
# Open http://localhost:5174/
```

### 2. Update Content
Edit `src/data/content.config.ts` to update:
- Headlines and descriptions
- Images and videos
- Links and CTAs
- Footer information
- Any other content

### 3. Customize Colors
Update theme colors in:
- `src/index.css` (CSS variables)
- `tailwind.config.js` (Tailwind colors)
- `src/theme/colors.ts` (TypeScript constants)

### 4. Build for Production
```bash
npm run build
npm run preview
# Deploy dist/ folder
```
